## 6. 转化文案自检（anti-slop）

- [ ] 没有"赋能 / 助力 / 打造"等空话
- [ ] 没有"Trusted by 10,000+"虚数
- [ ] 数字具体（"200 teams" 而非 "many teams"）
- [ ] CTA 动词具体（"Start free trial" 而非 "Submit"）
- [ ] 价格透明（不是 "Contact us"）
- [ ] 承诺具体（"14 天免费 · 无需信用卡" 而非 "free"）

## 7. 性能预算（单页比多页严）

- [ ] Lighthouse Performance ≥ 90（mobile）
- [ ] LCP ≤ 2.0s
- [ ] CLS ≤ 0.05
- [ ] JS 总量 ≤ 150KB（gzip）
- [ ] 首屏图 ≤ 100KB（WebP/AVIF）

## 8. 衡量（不衡量 = 没做）

- [ ] 转化率目标（如 5% 访客 → 注册）
- [ ] 转化事件埋点（GA4 / PostHog / 自建）
- [ ] A/B test 计划（哪个 CTA 文案 / 哪个 Hero 图）
- [ ] 漏斗分析（Hero → Feature → Pricing → CTA 各步转化率）
