# 专家 5 维度评审

> 融合 huashu-design 的评审知识。5 个维度的设计评估体系。

---

## 五个维度

### 1. 视觉层级 (Visual Hierarchy)

**评估内容**: 信息是否有明确的优先级引导

| 分数 | 标准 |
|------|------|
| 5 | 用户视线自然从最重要到最不重要流动，无需思考 |
| 4 | 大部分信息层级清晰，少量区域需优化 |
| 3 | 主要信息可辨识，但次要信息干扰较多 |
| 2 | 信息层级混乱，用户需费力寻找关键信息 |
| 1 | 无明确层级，所有信息视觉权重相同 |

**检查项**：
- [ ] 标题与正文有明确的大小/字重对比
- [ ] CTA 比周围元素更突出
- [ ] 信息分组通过间距/背景/边框清晰区分
- [ ] 视觉焦点引导用户视线向下移动

### 2. 信息架构 (Information Architecture)

**评估内容**: 内容的组织是否逻辑清晰

| 分数 | 标准 |
|------|------|
| 5 | 内容组织直觉化，用户无需思考即可找到目标 |
| 4 | 内容组织基本清晰，少量路径可优化 |
| 3 | 内容组织可理解，但需要学习成本 |
| 2 | 内容组织混乱，用户需反复尝试 |
| 1 | 内容无组织，用户无法找到目标 |

**检查项**：
- [ ] 导航层级不超过 2 级
- [ ] 同类信息归组，不同类信息分离
- [ ] 用户 3 秒内可判断产品/页面是什么
- [ ] 关键路径 CTA 在首屏可见

### 3. 情感共鸣 (Emotional Resonance)

**评估内容**: 设计是否传达了正确的情感调性

| 分数 | 标准 |
|------|------|
| 5 | 设计精准传达品牌情感，用户产生共鸣 |
| 4 | 设计基本传达品牌情感，少量偏差 |
| 3 | 设计传达了部分情感，但不够精准 |
| 2 | 设计情感调性模糊，无法产生共鸣 |
| 1 | 设计传达了错误的情感 |

**检查项**：
- [ ] 颜色选择与品牌调性一致
- [ ] 字体选择传达了正确的性格
- [ ] 图片/插图风格与品牌一致
- [ ] 整体氛围与目标用户期望匹配

### 4. 认知负荷 (Cognitive Load)

**评估内容**: 用户完成任务需要投入多少认知资源

| 分数 | 标准 |
|------|------|
| 5 | 用户可直觉操作，零学习成本 |
| 4 | 用户需少量学习，操作路径清晰 |
| 3 | 用户需一定学习，但可完成 |
| 2 | 用户学习成本高，需反复尝试 |
| 1 | 用户无法理解如何操作 |

**检查项**：
- [ ] 每屏核心操作不超过 3 个
- [ ] 操作流程不超过 5 步
- [ ] 错误状态有明确的恢复路径
- [ ] 复杂操作有引导/提示

### 5. 技术品质 (Technical Quality)

**评估内容**: 设计的技术实现质量

| 分数 | 标准 |
|------|------|
| 5 | 像素级精确，无任何技术瑕疵 |
| 4 | 整体精确，少量可忽略的瑕疵 |
| 3 | 基本可用，但存在明显技术问题 |
| 2 | 技术问题影响使用体验 |
| 1 | 技术问题导致无法使用 |

**检查项**：
- [ ] 颜色对比度 ≥ 4.5:1
- [ ] 所有交互元素有焦点状态
- [ ] 响应式在 5 个断点正常
- [ ] 动画帧率 ≥ 60fps
- [ ] 图片无压缩失真

| 维度 | 权重 | 分数(1-5) | 加权分 |
|------|------|----------|--------|

| 认知负荷 | 20% | | |

| **总计** | **100%** | | **/5** |

### 评级标准

| 综合分 | 评级 | 说明 |
|--------|------|------|
| 4.5-5.0 | ⭐⭐⭐⭐⭐ | 卓越 — 可作为标杆案例 |
| 3.5-4.4 | ⭐⭐⭐⭐ | 优秀 — 小幅优化即可上线 |
| 2.5-3.4 | ⭐⭐⭐ | 合格 — 需要针对性优化 |
| 1.5-2.4 | ⭐⭐ | 不足 — 需要大幅修改 |
| 1.0-1.4 | ⭐ | 失败 — 需要重新设计 |
