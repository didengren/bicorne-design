## Dark vs Light Selection Guide

| Signal | Choose Dark | Choose Light |
|--------|------------|-------------|
| Target Users | Developers, professional users | Mass consumers, enterprise clients |
| Use Case | Extended focus, code/data | Quick browsing, marketing showcases |
| Brand Tone | Engineering aesthetics, tech feel | Trust, professionalism, warmth |
| Content Type | Data-intensive, code-centric | Photography-centric, copy-centric |
| Platform | Large screens / control rooms, OLED mobile | Outdoor mobile, touch kiosks |
| Reference Brands | Linear, Framer, Cursor, HashiCorp, Sanity, ClickHouse, Ferrari | Stripe, Coinbase, Airbnb, Apple, PostHog, Mastercard |

## How to Use

1. Find recommended brands in the decision tree based on your project type
2. Read the corresponding brand's DESIGN.md
3. Map to token.json following `references/token-mapping/mapping-rules.md`
4. Use theme templates under `templates/` as the skeleton
5. Generate a token.json that conforms to `schema/design-token.schema.json`
