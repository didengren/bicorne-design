## 选择决策树

```
你的项目是什么类型？
│
├─ 中后台 / 管理系统
│   ├─ 开发者工具 → Linear, Raycast, Warp, Cursor
│   ├─ 金融/支付 → Stripe, Coinbase, Wise
│   └─ 通用管理 → Linear, Vercel, Notion
│
├─ 营销落地页
│   ├─ 电商/零售 → Nike, Airbnb, Shopify
│   ├─ SaaS 产品 → Stripe, Vercel, Linear
│   └─ 创意工具 → Figma, Framer, Notion
│
├─ AI 产品
│   ├─ 对话型 → Claude, Cohere
│   ├─ 工具型 → Cursor, Replicate
│   └─ 平台型 → Mistral.ai, Cohere
│
└─ 设计探索
    ├─ 暗色美学 → Linear, Framer, Cursor
    ├─ 亮色奢华 → Stripe, Coinbase
    └─ 色彩丰富 → Figma, Airbnb, Nike
```

## 暗色 vs 亮色选择指南

| 信号 | 选择暗色 | 选择亮色 |
|------|---------|---------|
| 目标用户 | 开发者、专业用户 | 大众消费者、企业客户 |
| 使用场景 | 长时间专注、代码/数据 | 快速浏览、营销展示 |
| 品牌调性 | 工程美学、科技感 | 信任感、专业感、温暖 |
| 内容类型 | 数据密集、代码为主 | 摄影为主、文案为主 |
| 参考品牌 | Linear, Framer, Cursor | Stripe, Coinbase, Airbnb |

## 使用方式

1. 根据项目类型，在决策树中找到推荐品牌
2. 读取对应品牌的 DESIGN.md
3. 按 `references/token-mapping/mapping-rules.md` 映射为 token.json
4. 使用 `templates/` 下的主题模板作为骨架
5. 生成符合 `schema/design-token.schema.json` 的 token.json
